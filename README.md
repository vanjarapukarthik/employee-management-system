Employee Management System

A REST API-based Employee Management System developed using Java, Spring Boot, and MySQL.

Technologies Used

- Java 17
- Spring Boot
- Spring JDBC (JdbcTemplate)
- MySQL
- Maven
- Postman
- Git and GitHub

Features

- Add a new employee
- Retrieve all employees
- Update employee details
- Delete an employee
- Store employee information in MySQL database

Database

Database Name: employee_ db

Table Name: employees

### API Endpoints

- POST /employees - Add employee
- GET /employees - Get all employees
- PUT /employees/{id} - Update employee
- DELETE /employees/{id} - Delete employee

How to Run

1. Clone this repository.
2. Open the project in Eclipse IDE.
3. Configure MySQL database credentials in application.properties.
4. Run EmployeeManagementApplication.java.
5. Test the APIs using Postman.
